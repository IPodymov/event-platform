# Принятые решения

Короткий журнал решений, которые не следуют напрямую из `CLAUDE.md`.

| Дата | Решение |
|---|---|
| 2026-10-26 | Платформенные роли (`user` / `moderator` / `admin`) не добавляются в `User` до задачи «Роли и права» (Sprint 9). |
| 2026-10-26 | Валюта MVP — только RUB. Поле `currency` в моделях денег не нужно; суммы — копейки в `BigIntegerField`. |
| 2026-10-26 | REST API аутентификации — `allauth.headless` (клиент `browser`, сессии + CSRF) под `/api/auth/`. Его OpenAPI-спецификация отдаётся allauth отдельно от drf-spectacular: `/api/auth/openapi.html`. |
| 2026-10-26 | Steam и Discord (и будущие сторонние провайдеры) — только привязка к существующему email-аккаунту и последующий вход. Регистрация через провайдера запрещена (`SocialAccountAdapter.is_open_for_signup`). Не больше одного аккаунта каждого провайдера на пользователя. Discord запрашивается со scope `identify` (email провайдера не используется), ID — через `selectors.get_discord_id`. Steam ID хранится в `allauth.socialaccount.SocialAccount` (`provider="steam"`, `uid` = SteamID64), читается через `apps.accounts.selectors.get_steam_id`. |
| 2026-10-26 | Модель `Game` и справочник дисциплин (Sprint 2) делаются перед задачей «Привязка игровых аккаунтов» (`GameAccount`, Sprint 1). |
| 2026-10-26 | Ник задаётся при регистрации (форма и API signup), профиль создаётся атомарно вместе с пользователем. Ник: 3–20 символов `[A-Za-z0-9_-]`, уникален без учёта регистра. Часовой пояс по умолчанию — `Europe/Moscow`. |
| 2026-10-26 | Аватары: Pillow, до 5 МБ, JPEG/PNG/WebP, перекодирование в WebP ≤ 512×512. Страны — `django-countries` (ISO 3166-1). |
| 2026-10-26 | Регионы (`apps/games/regions.py`): у аккаунтов CS2/Dota 2 региона нет, турниры — EU/CIS/NA/SA/ASIA/OCE; Hearthstone — Americas/Europe/Asia-Pacific; Wild Rift — RU/EUW/EUNE/TR (и для аккаунтов, и для турниров). |
| 2026-10-26 | `GameAccount` для CS2/Dota 2 создаётся из привязанного Steam автоматически и сразу подтверждён; удаляется при отвязке Steam. Riot ID и BattleTag вводятся вручную и подтверждаются модератором (пока — staff через админку; до задачи «Роли и права» и `AuditLog` фиксируются `verified_by`/`verified_at`). Один аккаунт на дисциплину у игрока; ID уникален в дисциплине без учёта регистра. |
| открыто | Блокирует ли неподтверждённый Riot ID / BattleTag регистрацию на турнир — решить в задаче «Регистрация участников» (Sprint 3). |
| 2026-10-27 | Пул карт CS2: стартовый пул не засеивается, администратор создаёт его в админке. Активный пул — ровно 7 разных карт, один на дисциплину; карты хранятся строками. |
| 2026-10-27 | Команды: название (до 32 символов) и тег (2–5 `[A-Za-z0-9]`) уникальны внутри дисциплины без учёта регистра; логотип — те же правила, что у аватара, WebP ≤ 256×256. `TeamMembership.game` денормализован, чтобы частичный уникальный индекс гарантировал одну активную команду игрока в дисциплине. |
